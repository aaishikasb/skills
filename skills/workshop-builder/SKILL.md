# Workshop builder

Design a session in which participants perform and explain a useful task within the actual room, equipment, and time constraints.

## Establish the teaching contract

Read the project, run notes, audience, duration, room format, hardware inventory, and staffing information. Distinguish participant prerequisites from things taught during the session. Use existing context; ask only for gaps that would change the exercise design.

Choose an observable learning outcome and the smallest working path that supports it. Check whether the intended number of learners can use the available devices concurrently. Assign roles and rotations for shared kits so each learner practices the important decision; watching a teammate type is not equivalent practice.

## Build the session

Budget time for setup, explanation, hands-on work, checkpoints, recovery, and closing assessment. Show elapsed ranges and check that the total fits. Treat unmeasured durations as estimates. Keep advanced extensions optional and outside the core path.

For each exercise specify starting state, learner action, visible success signal, and a question that reveals understanding. Include an instructor hint and a known-good checkpoint learners can resume from. A checkpoint should preserve learning progress without requiring them to repeat all setup.

Plan for the environment that exists: device availability, supported host systems, power and cabling, network access, model/data downloads, account creation, and permission constraints. Preload large assets when appropriate. Keep any electrical or motion setup tied to verified device documentation and established operating limits.

Build a recovery branch for the most likely session blocker, with a time limit before switching. A recorded input, simulator, or paired observer role must be labeled and must preserve whatever part of the learning outcome it can actually teach; explain what it cannot verify. Avoid a fallback that quietly turns an on-device objective into a desktop claim.

Separate participant instructions from instructor answers, checkpoints, and facilitation notes. Finish with a small transfer task using a changed input or constraint, with an answer key for the instructor.

## Deliver

Produce the requested workshop plan or materials with a timed agenda, exercise cards, setup checklist, recovery branches, and exit check. Reuse the actual repository commands and artifacts; mark anything awaiting a rehearsal. Preparing materials does not register participants, send invitations, buy equipment, or operate hardware.

The plan is ready for rehearsal when the timetable fits, every exercise has a checkpoint and recovery route, and equipment allocation is workable. Call it rehearsed only after observing a run, with setup time and failure recovery included. State which learner outcomes still require a participant trial.
